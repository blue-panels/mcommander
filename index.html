M-Commander

Based on GNU Midnight Commander

The package is called mcommander and installs next to the distribution's mc. It grows outside the core: panel contents come from loadable plugins, scripts talk to it through a versioned host ABI, and the shell runs in an embedded terminal.

Installing

Packages for every release

Packages for Debian, Ubuntu, Fedora, Arch and macOS are attached to every GitHub release. The package is called mcommander and installs next to the distribution's mc instead of replacing it.

Ubuntu 24.04, 26.04PPA 
sudo add-apt-repository ppa:bluepanels/mcommander
sudo apt update
sudo apt install mcommander mcommander-plugins mcommander-lua
macOS, LinuxHomebrew 
brew install blue-panels/tap/mcommander
Debian 13files from the release 
sudo apt install ./mcommander{,-plugins,-lua}_*debian13*_amd64.deb
Fedorafiles from the release 
sudo dnf install ./mcommander{,-plugins,-lua}-6*.x86_64.rpm
Archfiles from the release 
sudo pacman -U ./mcommander{,-plugins,-lua}-6*-x86_64.pkg.tar.zst
From sourcemeson 
git clone https://github.com/blue-panels/mcommander.git
cd mcommander
meson setup build --prefix=/usr --sysconfdir=/etc
meson compile -C build
sudo meson install -C build

The latest release has .deb files for Debian 13 and Ubuntu 26.04 (amd64, arm64), .rpm for Fedora (x86_64, aarch64), .pkg.tar.zst for Arch, and a .dmg and .pkg for macOS. On arm64 (aarch64 for Fedora), change the architecture in the file name. INSTALL lists the build dependencies.

The main command is mcommander, with mc6 as a short alias. The editor, viewer and compare view are mcedit6, mview and mcdiff6, and mctree and mcstruct start the structured views. None of them takes the names of GNU mc, so both can be installed at once. The user directories are ~/.config/mc6, ~/.local/share/mc6 and ~/.cache/mc6. On first start the matching mc directory is copied into each new one, and the original is left untouched.

Panel plugins

A panel that shows more than files

A plugin panel works like a regular file panel: navigation, viewing, and the standard operations through F4, F5 and F6. Plugins add their own data sources, menu entries, settings and help, and keep a navigation history of their own. One plugin can hand another an open seekable stream, and magic.ini routes a file to the plugin that understands it. That is what lets an archive on a remote host open without downloading it whole.

PluginWhat it does
arcmcArchives in a panel, on libarchive. Browse nested archives, add and delete files, create ZIP, 7z, TAR and CPIO, set compression, passwords and encryption, extract in bulk with progress, speed and remaining time. Paths are checked on extraction so an archive cannot escape the target directory. Guide
mcstructStructured binary viewer and editor. A text def-file (STL5, compatible with the DOS Struct Look) turns a firmware image, a header or a table file into a tree of named fields synced with a hex dump. Ships def-files for ELF, PE, ZIP, DBF, MBR, FAT, uImage, DTB, PNG, BMP and WAV. Guide
duplicatesFinds copies of files in a directory, and in the other panel too, by size, name or content. Files are compared by size, then by a hash of their first and last 4 KiB, then by a hash of the whole file, and the hashes are kept for the next search. "Similar content" also groups pictures that look the same and texts that differ only in line endings and spaces. The other panel can be a reference directory whose files are never moved or deleted.
GitCommits, branches and changed files with the built-in diff viewer. All the changes of a branch in one folder, merge conflicts resolved in the three-way merge on Shift-F3. Repositories can be saved as favourites.
GitHubThe pull requests and issues of a repository, with the description in Quick View.
PostgreSQLServers, databases, schemas and tables. F3 on a table shows its SQL and its first rows as a table, Alt-F3 opens a query console.
mcpeek.NET assemblies as trees of references, namespaces, types and members. Decompiled C# or IL, usages across assemblies, export of namespaces as projects.
DockerContainers, their files, images, volumes, networks, mounts, command execution and logs. Local and SSH profiles. Log fetch parameters and a formatting pipe are set right in the viewer; a formatter for .NET and Serilog logs is included.
KubernetesPods, nodes, services and workloads through kubectl. Contexts, namespaces, describe, YAML, exec, resource deletion and log viewing.
MongoDBConnections, databases, collections and documents. Filtering, projection, sorting, limits, paged reading of large collections and document editing. F3 on a collection shows its documents as a table, Alt-F3 opens a query console.
S3Upload, download and delete objects, create buckets, view metadata, stream objects into the viewer. Works with MinIO, Ceph and Cloudflare R2.
SQLiteA database as a panel of tables, views and rows. F3 shows a table, a view or a page of rows as a table. Read only.
FTP / SFTPFTP and FTPS with active and passive mode, proxies, keepalive and IP version settings. SFTP with password and key authentication, compression, progress and streaming. These replace the old ftpfs and sftpfs.
SambaSMB servers and their shares.
ACL editorPOSIX and Windows access control lists, from the Attributes menu.
systemd, shell, External PanelizeUnits, shell connections, and a panel filled by a command's output.

Finding duplicates

Command > Find duplicates... runs the search in the background, and "Show found" opens a panel with the groups. Similar pictures are grouped by a perceptual hash, Quick View shows the one under the cursor, and F8 asks before a group loses its last copy.

A database as a panel

Tables, views and the schema of an SQLite file, each shown as a table on F3. MongoDB and PostgreSQL work the same way.

GitHub pull requests

The merged pull requests of the repository, one of them in Quick View.

Creating an archive from tagged files

Tag files, open the pack dialog, pick the format and compression, watch the progress. The built-in tar and cpio filesystems are gone; arcmc does that job now.

mcstruct on a DBF file

Header fields with the hex dump and the def-file in sync, and the records as a grid. Start it with mcstruct FILE, Shift-F4 in the viewer, or F3 on a file that magic.ini hands to it.

A plugin module is opened the first time it is used, so the plugins do not slow down the start. User plugins are loaded from ~/.local/lib/mc6/panel-plugins. The plugins are tried in a Docker sandbox described on the QA testing page.

Scripting

Lua as a plugin, not a core feature

Lua support is a plugin that speaks the core ABI, so the language is not built into mc. A script can read and change editor documents in transactions, provide panels and file operations, supply the viewer with generated content, build native dialogs and full screens of widgets, run processes and answer events.

Scripts are managed in the Manage Plugins dialog, where a Lua package can also have its own settings dialog. Scripts can use the syntax engine of the editor through mc.syntax.scan(). Several of the viewers on this page, the Markdown, PDF and image renderers among them, are Lua scripts themselves.

Viewer

mcview reads Markdown, structure, images and logs

Markdown

Headings, lists, tables, links, footnotes and fenced code with the editor's syntax highlighting. Mermaid flowcharts, sequence and class diagrams and display math are drawn in the terminal. Links use OSC 8 where the terminal supports it.

A large document is rendered in parts, so the first screen appears at once and the rest follows while the viewer stays responsive.

Tree mode

JSON, YAML, XML, HTML, and the metadata of PNG and JPEG open as a tree, in the fullscreen viewer and in Quick View. Expand and collapse nodes, set the depth, search the whole structure, and copy the path of the selected element in a jq-like form.

The mcview_structured_auto option makes supported files open in tree mode by default.

Live logs with a filter

The viewer works with commands that never finish, such as docker logs -f or journalctl -f. Data is read without blocking the interface and shown as it arrives.

The filter offers plain search, regular expressions, case sensitivity, whole words and charset selection, and applies to the current source: only matching lines are shown, with no second file or process.

For Docker and Kubernetes logs, the number of records, the time range, the previous instance and continuous refresh are set in the viewer, and the stream can be piped through an external formatter.

Images and generated views

PNG, JPEG and other raster images are rendered by Chafa into terminal characters and redrawn on resize. Where the terminal draws sixel graphics, the real picture is shown instead.

The same mechanism gives other files a readable form: PDF pages as searchable text with their pictures, ELF binaries through readelf, Java classes decompiled by Procyon, dBase, FoxPro and Clipper tables as pageable grids. F8 switches between the generated view and the bytes.

Reading cursor and selection

A visible cursor, selection with the keyboard or the mouse, word and line selection, copy to the clipboard. ANSI and nroff formatting is stripped from the copied text.

Syntax highlighting

The viewer and the compare view use the editor's syntax rules. Search for plain text or hex in large files is many times faster than before.

Manual pages

nroff mode reads SGR styles, OSC 8 links and overstrike sequences, and formats in the charset of the locale.

ANSI colours

Standard and bright colours, the 256-colour palette, True Color, bold, underline, italics and reverse video. Shift-F9 toggles rendering.

Terminal replay

Positioning, screen erasing and scrolling regions are handled, so script(1) recordings and saved output of fullscreen programs can be viewed. F9 switches None, SGR and Term.

Runtime file handlers

A Lua handler can intercept a file in Viewer or Quick View and show a generated representation. The rules live in magic.ini and can be changed by the user.

Editor

mcedit with plugins, folding and history

Code folding

Multi-line blocks fold by their {}, [] and () brackets, through the gutter indicator, the Command menu or Alt+Shift+F. The command uses the selection or the nearest enclosing block.

Editor plugins

A plugin can register actions, add menu entries and handle keys. Three ship with the editor: the spell checker, etags support, and a ctags navigator with jumps to definitions, references, symbol search, completion and a jump history. User plugins load from ~/.local/lib/mc6/editor-plugins.

Nested syntaxes

One syntax can be embedded in another: scripts and style sheets in HTML, code blocks in Markdown by the language they name, awk, Python and SQL inside shell scripts. New rules for Jinja2, Smarty, Mermaid and git commit messages.

Paste and clipboard

A bracketed paste comes in as one block and is undone in one step. The clipboard remembers the codeset of the copied text, and a paste into a file with another codeset recodes it.

Control characters

Shown in caret notation or hidden. Hidden characters take no screen cell, and the cursor moves over them together with the text around them.

Line filter

The Search dialog (F7) has a Filter action that hides non-matching lines while keeping the original numbers. Alt+S lifts or restores the filter, Alt+Shift+S filters by the selection or the word under the cursor.

Undo history

Alt+Shift+U lists undo and redo groups with the line, the operation, the size and a fragment of the change. Jump to any point of the history.

Macro explorer

Alt+Shift+M lists recorded macros. Inspect the action sequence, run, delete, or open the definition in mc.macros.

Saving through sudo

When a file cannot be saved for lack of permissions, the editor offers to repeat through sudo -S tee. A failed attempt keeps the buffer and the editor open.

Long lines

Character positions inside long lines are cached, so logs, CSV and minified data scroll and redraw without delays.

Embedded terminal

mcterm in place of the subshell

The shell runs inside the file manager. A command typed on the command line goes to the shell already running there, and the command line shows that shell's own prompt, colours and cursor. Ctrl+O toggles the terminal; it starts in the directory of the active panel and follows it, tracking the prompt, the running command, the exit status and the directory through OSC 133 and OSC 7.

  • Bounded scrollback: PgUp/PgDn, Shift+arrows, Home, End and the wheel. Typing returns to the live output.
  • Selection with the mouse or Shift+arrows, copy with Ctrl+Insert. The OSC 52 clipboard of a program reaches the clipboard too.
  • Alt+S searches the scrollback, Alt+Shift+S keeps only the matching rows.
  • The full kitty keyboard protocol, for the panels and for the programs in mcterm. While a modifier is held, the key bar can show the commands of the F keys with it.
  • Sessions: with the session plugin, mc survives a closed terminal or a dropped connection, and the next start returns to the same session.
  • Wide characters, long lines that wrap and are laid out again when the width changes, sixel graphics.
  • bash and fish start with the integration of M-Commander; F7, Shift-F4 and other file manager keys work with the panels hidden.

Terminal emulation is done by the viewer's own engine, without an external library.

Compare view

Three-way merge with git's xdiff

The compare view (mcdiff6, or Ctrl-X f in the panels) compares files with the xdiff code of git inside the program instead of running diff.

It merges three files: pick the base of the merge, see which file is active and in which direction a change is copied. The git panel shows the files in conflict and opens this merge on Shift-F3; the result can be added to the index right there.

Syntax highlighting works here too, on top of the diff backgrounds and changed-word marks.

Panels, keys and skins

Configuration that used to need a text editor

Key Bindings

Changes the bindings and finds conflicts between them, grouped by area into tabs.

Learn Keys

Recognises modifiers, so Ctrl, Alt and Shift are captured together with the base key. Settings are stored per $TERM in ~/.config/mc6/term/.

Key Sniffer

Shows the escape sequence a terminal sends for a key, with the shortcut, the mapped action and the keycode.

Panel view modes

Users define their own display modes and choose the set and width of the columns. permission_colors colours each permission bit by what it is, the way eza does.

Quick filter

Alt+Shift+S filters the panel as you type, Ctrl+G removes the filter. Alt+C asks for a directory in the mini status, with completion above the input.

51 skins

Every shipped skin has colours for all screens, including mcterm, the tree view and mcstruct. Mashdark and Tokyo Night are among them, with -thin, -defbg and root variants. Skins

Hotlist and User Menu

The Hotlist keeps plugin locations as well: a Git repository, a container, an archive. The User Menu edits itself: entries and submenus are added, moved and imported in a dialog, and entries can have conditions.

Directory watching

Local panels follow changes on disk through inotify. Marking ten thousand files by a mask takes a fraction of a second.

Far mode

An opt-in mode with the keys of Far Manager, including the fast find on Alt with a character. Windows Terminal's Win32 input mode is read too.

Key bar with modifiers

While Shift, Ctrl or Alt is held, the key bar shows what the F keys do with that modifier: sorting on Ctrl, the single-file operations on Shift, the plugin drives, Find and Tree on Alt. Release the key and the usual labels come back.

It needs a terminal with the kitty keyboard protocol, such as kitty, and is turned on by keybar_modifiers=true in the settings file.

Skin editor

Changes the colours and the frame characters of a skin from inside mc and shows the result as it goes. The left half lists every key of the skin by the part of the screen it paints, the right half is a sample drawn with the colours as they are now.

The Color dialog has the 16 named colours, the 256-colour picker and RGB input, plus bold, italic, underline, reverse and blink. Every change goes to the screen at once. Saving writes a copy to your skins directory and makes it the running skin. Opened from Command, Plugin panel or Manage Plugins.
