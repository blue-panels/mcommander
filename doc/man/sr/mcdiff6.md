# НАЗИВ <!-- help:skip -->

mcdiff6 - Уграђени diff прегледач ГНУ-овог поноћног наредника..

# УПОТРЕБА <!-- help:skip -->

**mcdiff6**
[-bcCdfhstVx?] дато1 дато2

# ОПИС

mcdiff6 је веза ка
**mcommander**-у,
главној извршној датотеци ГНУ-овог поноћног наредника. Извршавање ГНУ-овог
поноћног наредника под овим именом захтева покретање уграђеног diff прегледача,
који пореди
*дато1*
са
*дато2,*
задатим у командној линији.

# ОПЦИЈЕ

*-b*
: Намеће црно-бели приказ.

*-c*
: Намеће колор режим на терминалима на којима је
**mcdiff6**
подразумевано црно-бео.

*-d*
: Деактивира подршку за миша.

*-f*
: Приказује укомпајлиране путање за претрагу за датотеке Поноћног наредника.

*-S арг, --skin=арг*
: Задаје назив скина у командној линији.

*-t*
: Користи се само ако је код компајлиран са S-Lang-ом и terminfo-ом: чини да
Поноћни наредник користи вредност променљиве
**TERMCAP**
за информације о терминалу уместо информација из системске базе терминала

*-V*
: Приказује верзију програма.

*-x*
: Намеће xterm режим. Користи се на терминалима сагласним са xterm-ом (два
екранска режима и способност за слање ескејп секвенци миша).

# Уграђени Diff прегледач <a id="diff-viewer"></a>

mcdiff6 је визуелни diff алат. Можете поредити две датотеке и уређивати их на
лицу места, а разлика се рачуна поново након сваке измене. Отвара га и
панелски прикључак git, са датотеком каквом је види HEAD са једне стране и
датотеком радног стабла са друге.

Следеће пречице су доступне у уграђеном diff прегледачу:

**F1**
: Позива уграђени хипертекстуални прегледач помоћи.

**F2**
: Чува измењене датотеке.

**F4**
: Уређује датотеку левог панела у уграђеном уређивачу.

**F14**
: Уређује датотеку десног панела у уграђеном уређивачу.

**F5**
: Преноси текуће парче у датотеку са десне стране. Преноси се само текуће
парче, а разлика се затим рачуна поново.

**F15**
: Преноси текуће парче у супротном смеру, у датотеку са леве стране.

**F7**
: Почиње претрагу.

**F17**
: Наставља претрагу.

**F9**
: Отвара
[опције поређења](#diff-options).

**Alt-e**
: Бира скуп знакова у ком се читају обе датотеке.

**F10, Esc, q, Q**
: Излази из diff прегледача.

**Alt-s, s**
: Смењује приказивање статуса парчета.

**Alt-n, l**
: Смењује приказивање бројева линија.

**Ctrl-s**
: Смењује истицање синтаксе. Текст сваког реда се боји по правилима синтаксе,
на исти начин као у уграђеном уређивачу, а стање реда остаје на позадини и на
колони ознака. Тамо где скин разликује измењену реч од остатка реда само бојом
текста, реч се уместо тога подвлачи. Подешавање се памти одвојено од истог
подешавања уређивача.

**f**
: Максимизује леви панел.

**=**
: Изједначава ширину панела.

**>**
: Смањује величину десног панела.

**<**
: Смањује величину левог панела.

**2, 3, 4, 8**
: Поставља величину табулације.

**C-u**
: Размењује садржај diff панела.

**C-r**
: Поново чита обе датотеке и рачуна разлику изнова.

**C-o**
: Приказује командни екран.

**Enter, Space, n**
: Тражи следеће diff парче.

**Backspace, p**
: Тражи претходно diff парче.

**g, G**
: Иде на линију.

**Down**
: Скролује једну линију унапред.

**Up**
: Скролује једну линију уназад.

**PageUp**
: Премешта се једну страну нагоре.

**PageDown**
: Премешта се једну страну надоле.

**Left, Right**
: Помера текст за једну колону у страну.

**C-Left, C-Right**
: Помера текст за осам колона у страну.

**Home**
: Враћа се на прву колону.

**C-Home**
: Премешта се на почетак датотеке.

**C-End**
: Премешта се на крај датотеке.

# Опције поређења <a id="diff-options"></a>

Подешавања
[уграђеног поређења](#diff-viewer),
која отвара
**F9**
на истом месту и ставка
**Опције Diff прегледача**
менија „Опције“ менаџера датотека. Поређење узима подешавања при покретању, па
већ отворен прозор задржава она са којима је отворен.

*Алгоритам поређења.*
Обичан пореди датотеке какве јесу. Најбржи претпоставља да су велике и
задовољава се грубљим исходом. Најмањи троши више времена да нађе мањи скуп
разлика.

*Занемари величину слова.*
Велика и мала слова рачунају се као исти знак.

*Занемари ширење табулатора.*
Редови који се разликују само по томе чиме је писано исто увлачење, табулаторима
или размацима, рачунају се као једнаки.

*Занемари промене размака.*
Низ размака рачуна се као једнак сваком другом низу размака.

*Занемари све размаке.*
Размаци не учествују у поређењу.

*Уклони завршни знак новог реда.*
Одбацује се повратак кола на крају реда, па се датотека са DOS крајевима редова
пореди са оном са Уникс крајевима.

# ДАТОТЕКЕ

*{{pkgdatadir}}/help/mcommander.md*
: Датотека помоћи за овај програм.

*{{pkgdatadir}}/mc.ini*
: Подразумевана системска подешавања ГНУ-овог Поноћног наредника, која се користе
само ако не постоји корисничка датотека ~/.config/mc6/ini.

*{{pkgdatadir}}/defaults.ini*
: Глобална подешавања Поноћног наредника. Подешавања у овој датотеци утичу на све
кориснике, без обзира на то да ли имају ~/.config/mc6/ini или не.

*~/.config/mc6/ini*
: Корисничка подешавања. Ако је ова датотека присутна, онда се подешавања
учитавају одавде уместо из системске датотеке са подешавањима.
