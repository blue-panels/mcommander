# НАИМЕНОВАНИЕ <!-- help:skip -->

mcdiff6 - встроенная программа сравнения файлов M-Commander.

# СИНТАКСИС <!-- help:skip -->

**mcdiff6**
[-bcCdfhstVx?] файл1 файл2

**mcdiff6**
[-bcCdfhstVx?] [-o результат] свой база чужой

**mcdiff6**
[-bcCdfhstVx?] [-o результат] -B база свой чужой

# ОПИСАНИЕ

mcdiff6 - это ссылка на
**mcommander**,
основной исполняемый файл M-Commander. Запуск M-Commander под этим именем
открывает встроенную программу сравнения для двух файлов, указанных в
командной строке. С тремя файлами она сливает
*свой*
и
*чужой*
файлы, две изменённые версии файла
*база*;
см.
[Слияние трёх файлов](#merge).
Ключи командной строки описаны в mcommander(1).

# ОПЦИИ <a id="options"></a>

*-b*
: Черно-белый режим отображения.

*-c*
: Цветной режим на терминалах, где
**mcdiff6**
по умолчанию работает в черно-белом.

*-d*
: Отключить поддержку мыши.

*-h, -?, --help*
: Показать ключи и то, что они делают.

*-B файл, --base=файл*
: Общая база двух файлов: открыть их слияние трёх файлов, как если бы база
стояла между ними.

*-o файл, --output=файл*
: Куда сохранить слияние трёх файлов. Без этого ключа слияние сохраняется в
файл базы.

*-f*
: Показать вкомпилированные пути поиска файлов M-Commander.

*-S имя, --skin=имя*
: Задать имя скина в командной строке. Подробнее смотрите раздел
**Скины**
в mcommander(1).

*-s*
: Работа на медленном терминале: экран перерисовывается реже.

*-t*
: Работает только если программа собрана с S-Lang и terminfo: заставляет
M-Commander брать сведения о терминале из переменной
**TERMCAP**,
а не из общесистемной базы терминалов.

*-V*
: Показать версию программы.

*-x*
: Включить режим xterm. Применяется на терминалах, которые умеют то же, что и
xterm: два режима экрана и последовательности мыши.

# Встроенная программа сравнения файлов <a id="diff-viewer"></a>

mcdiff6 - это средство наглядного сравнения. Два файла можно сравнить и тут же
править, различия считаются заново после каждого изменения. Панельный плагин
git открывает его сам: с одной стороны файл таким, каким его видит HEAD, с
другой - файл рабочего дерева.

Ниже перечислены клавиши встроенной программы сравнения файлов.

**F1**
: Вызов встроенной помощи.

**F2**
: Сохранение изменений в файлах.

**Tab**
: Сменить активный файл. Его рамка двойная, рамка другого файла одинарная и
серая. Метка на рамке активного файла показывает верхнюю строку: с ней
работают F5 и F15.

**F4**
: Редактирование активного файла во встроенном редакторе.

**F14**
: Редактирование другого файла во встроенном редакторе.

**F5**
: Скопировать текущее изменение из активного файла в другой. Текущее
изменение - то, что на верхней строке. Копируется только оно, после чего
различия считаются заново. Направление видно на панели клавиш: "Copy->" или
"<-Copy".

**F15**
: Скопировать текущее изменение в обратную сторону, из другого файла в активный.

**Shift-F6**
: Слить два файла относительно их общей базы: программа спрашивает файл базы
и показывает слияние трёх файлов. F2 там сначала спросит, куда сохранить
результат.

**F7**
: Вызов диалогового окна для задания шаблона поиска.

**F17**
: Продолжение поиска в соответствии с ранее определённым шаблоном.

**F9**
: Открыть
[настройки сравнения](#diff-options).

**Alt-e**
: Выбрать кодировку, в которой читаются оба файла.

**F10, Esc, q, Q**
: Выход.

**Alt-s, s**
: Включить/выключить показ статуса различий.

**Alt-n, l**
: Включить/выключить показ номеров строк.

**Ctrl-s**
: Включить/выключить подсветку синтаксиса. Текст каждой строки раскрашивается
по правилам синтаксиса так же, как во встроенном редакторе, а состояние строки
остаётся за фоном и колонкой пометок. Если скин отличает изменённое слово от
остальной строки только цветом текста, слово вместо этого подчёркивается.
Настройка запоминается отдельно от такой же настройки редактора.

**f**
: Показать на весь экран только активный файл.

**=**
: Сделать панели равными по ширине.

**>**
: Уменьшить правую панель.

**<**
: Уменьшить левую панель.

**2, 3, 4, 8**
: Установить размер табуляции.

**C-u**
: Поменять панели местами.

**C-r**
: Перечитать оба файла и посчитать различия заново.

**C-o**
: Показать экран команд (терминал).

**Enter, Space, n**
: Перейти к следующему различию.

**Backspace, p**
: Перейти к предыдущему различию.

**g, G**
: Перейти к строке.

**Down**
: Прокрутить на строку вперёд.

**Up**
: Прокрутить на строку назад.

**PageUp**
: На страницу вверх.

**PageDown**
: На страницу вниз.

**Left, Right**
: Сдвинуть текст на колонку вбок.

**C-Left, C-Right**
: Сдвинуть текст на восемь колонок вбок.

**Home**
: Вернуться к первой колонке.

**C-Home**
: В начало файла.

**C-End**
: В конец файла.

# Слияние трёх файлов <a id="merge"></a>

С тремя файлами программа сравнения показывает три колонки: слева свой
файл, в середине результат слияния, справа чужой файл. Боковые файлы не
меняются никогда, сохраняется только средняя колонка.

В начале средняя колонка - это файл базы, в который уже взяты все правки,
сделанные только одной стороной. Там, где обе стороны изменили одни и те же
строки, каждая по-своему, в середине остаются строки базы: это конфликт. Он
показан цветом конфликта, а их число стоит после "Cnf" в строке состояния
средней колонки. Строки, которые обе стороны изменили одинаково, тоже
берутся.

На верхней линии рамки средней колонки после "Result:" указан файл, куда
сохраняется результат, а на нижней после "Base:" - файл базы.

После каждой правки средней колонки различия считаются заново. Экран уже
40 колонок показывает оба файла рядом сверху, а среднюю колонку под ними.

**F5**
: Добавить строки левого файла в текущий блок средней колонки, после того,
что в нём уже есть. Текущий блок - тот, что на верхней строке, или первый
блок на экране.

**Shift-F5**
: Убрать строки левого файла из блока обратно. Если в блоке не осталось ни
одной стороны, в нём строки базы: конфликт снова становится конфликтом.

**F6**
: Добавить строки правого файла в блок. Если добавлены обе стороны, строки
идут в том порядке, в каком их добавляли.

**Shift-F6**
: Убрать строки правого файла обратно.

**], [**
: Перейти к следующему или предыдущему конфликту.

**Enter, Space, n; Backspace, p**
: Перейти к следующему или предыдущему блоку.

**F4**
: Редактировать среднюю колонку в редакторе. Блок, исправленный там,
считается решённым.

**F2**
: Сохранить среднюю колонку. Если конфликты остались, программа сначала
спрашивает.

**F10**
: Выйти. Если средняя колонка изменена и не сохранена, программа
спрашивает, сохранить ли её. Выход без изменений оставляет файлы как есть.

Программа завершается с кодом 0, если слияние сохранено без оставшихся
конфликтов, и с кодом 1 в остальных случаях, поэтому её можно сделать
инструментом слияния git:

```
[merge]
    tool = mcdiff
[mergetool "mcdiff"]
    cmd = mcdiff6 "$LOCAL" "$BASE" "$REMOTE" -o "$MERGED"
    trustExitCode = true
```

# Настройки сравнения <a id="diff-options"></a>

Настройки
[встроенной программы сравнения файлов](#diff-viewer).
Их открывает её собственное меню
**Настройки**,
а также пункт
**Настройки сравнения**
меню "Настройки" файлового менеджера. Программа сравнения берёт эти
настройки при запуске, поэтому уже открытое окно сравнения остаётся с теми,
с которыми было открыто.

*Алгоритм сравнения.*
Обычный сравнивает файлы как есть. Быстрый использует алгоритм histogram,
который остаётся быстрым, когда файлы сильно различаются. Минимальный тратит
больше времени, чтобы найти меньший набор различий.

*Игнорировать регистр.*
Прописные и строчные буквы считаются одним и тем же символом.

*Игнорировать развёртывание табуляций.*
Строки, которые отличаются только тем, чем записан один и тот же отступ,
табуляциями или пробелами, считаются одинаковыми.

*Игнорировать изменения пробелов.*
Любая цепочка пробельных символов считается равной любой другой.

*Игнорировать все пробелы.*
Пробельные символы не участвуют в сравнении.

*Убирать перевод каретки в конце строк.*
Символ возврата каретки в конце строки отбрасывается, поэтому файл с
концами строк DOS сравнивается с файлом с концами строк Unix.

# ФАЙЛЫ <a id="files"></a>

*{{pkgdatadir}}/help/mcommander.md*
: Файл помощи программы.

*{{pkgdatadir}}/mc.ini*
: Общесистемные установки M-Commander по умолчанию; используются только
тогда, когда у пользователя нет своего файла ~/.config/mc6/ini.

*{{pkgdatadir}}/defaults.ini*
: Общие установки M-Commander. Они действуют на всех пользователей,
независимо от того, есть у них ~/.config/mc6/ini или нет.

*~/.config/mc6/ini*
: Собственные установки пользователя. Если этот файл есть, установки
читаются из него, а не из общесистемного файла.
